How it works

Fragtape is a small Rust app. It starts its own hidden copy of OBS Studio only while a game is being recorded, with its own settings: your normal OBS is never touched. Between games only the game detection runs (about 2 ms every 2 seconds). This window can be closed: Fragtape keeps running in the tray.
