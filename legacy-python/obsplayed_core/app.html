How it works

OBSPlayed starts its own hidden copy of OBS Studio only while a game is being recorded, with its own settings: your normal OBS is never touched. Between games only the game detection runs (about 2 ms every 2 seconds). This window can be closed: OBSPlayed keeps running in the tray.
